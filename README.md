# 🤖 Friend Group Super-Bot (บอทประจำกลุ่มเพื่อนครบจบในตัวเดียว)

โปรเจกต์บอท Discord ภาษา Python ที่รวม **6 ฟีเจอร์สุดปั่นสำหรับเซิร์ฟเวอร์กลุ่มเพื่อน** ไว้ในบอทตัวเดียว พร้อมคำสั่ง `/upgrade_server` ที่ช่วยเนรมิตห้องใหม่และระบบทั้งหมดเข้าเซิร์ฟเวอร์เดิมของคุณในคลิกเดียว!

---

## ✨ ฟีเจอร์ทั้งหมดในบอทตัวนี้

1. **✨ อัพเกรดเซิร์ฟเวอร์อัตโนมัติ (`/upgrade_server`)**
   - สร้างหมวดหมู่ `✨ โซนพิเศษชาวแก๊ง` (มีห้อง `#🌟・hall-of-fame` และ `➕ สร้างห้องคุย`)
   - สร้างหมวดหมู่สถิติแยกต่างหาก **`☀️/🌙 สถิติชาวแก๊ง (Statistics)`** พร้อมห้อง `#☀️/🌙・สถิติชาวแก๊ง` ที่เปลี่ยนอีโมจิตามเวลาเช้า (`☀️` 06:00–17:59) และกลางคืน (`🌙` 18:00–05:59) ให้อัตโนมัติ!
2. **📌 บันทึกประวัติศาสตร์หน้ามืด (`cogs/hall_of_fame.py`)**
   - **Starboard:** แค่เพื่อนในกลุ่มกดอีโมจิ `💀`, `⭐`, `😂`, `🔥` หรือ `🗿` ครบ 3 คน บอทจะแคปข้อความและรูปส่งเข้าห้อง `#hall-of-fame` อัตโนมัติ
   - **สร้างรูปคำคมขาวดำ:** คลิกขวาที่ข้อความหลุดๆ ของเพื่อน -> เลือก **Apps -> 📸 สร้างรูปคำคมจากข้อความนี้** หรือใช้ `/quote_add` และสุ่มคำคมเก่าด้วย `/quote_random`
3. **⚖️ คำสั่งศาลเตี้ยประจำกลุ่ม (`cogs/friend_court.py`) — ใช้เป็น Command ได้ทุกห้อง!**
   - **ฟ้องเอาผิดเพื่อน (`/sue`):** เลือกบทลงโทษได้ครบทั้ง **`🔇 Mute ปิดไมค์ห้องคุย`**, **`⏳ Timeout ห้ามพิมพ์/ห้ามพูด`**, **`🦵 Disconnect เตะออกห้องคุย`**, และ **`🏷️ เปลี่ยนชื่อเล่นประจาน`** (สามารถตั้งชื่อประจานแถมคู่กับโทษอื่นได้ด้วย!)
   - **สั่งลงโทษด่วนเฉพาะแอดมิน (`/punish`):** แอดมินสามารถสั่งลงโทษเพื่อนได้ทันทีโดยไม่ต้องรอโหวต `/sue` (รองรับทะลุสิทธิ์แอดมิน/เจ้าของดิสเหมือนกัน)
   - **อภัยโทษ (`/pardon`):** ล้างบทลงโทษทั้งหมด (ปลดแบน / ปลดไมค์ / คืนชื่อเดิม) ได้ทันทีทั้งโทษจาก `/sue` และ `/punish`
   - **มีเวลาเปิดศาลให้คุยเถียงกันก่อนตัดสิน:** เลือกเวลาไต่สวนได้ตั้งแต่ 30 วินาที – 5 นาที (ไม่ตัดจบมั่วตอนโหวตครบ 3 คน) มีปุ่ม `🗣️ จำเลยแก้ต่าง`, `🕵️ พยานแฉเพิ่ม`, `⏱️ ต่อเวลาคุย +1 นาที` และพอหมดเวลาบอทจะทุบค้อนตัดสินลงโทษให้อัตโนมัติ!
   - **เช็คประวัติอาชญากรรม (`/criminal_record`):** ดูแฟ้มคดีความและบทลงโทษย้อนหลังของเพื่อนแต่ละคน หรือดูอันดับอาชญากรตัวตึงประจำกลุ่ม
4. **☀️/🌙 หมวดหมู่และบอร์ดสถิติชาวแก๊ง (`cogs/activity_stats.py`)**
   - **แยกหมวดหมู่แสดงชัดเจนว่าใครเล่นเกมไหนบ้าง:**
     - **👤 สมาชิกแต่ละคนเล่นเกมไหนบ้าง:** แจกแจงรายคนเลยว่าแต่ละคนเล่นเกมอะไรไปบ้าง เกมละกี่ชั่วโมง
     - **🔥 หมวดเกมยอดฮิต (เกมนี้ใครเล่นบ้าง):** แยกตามชื่อเกมว่าแต่ละเกมมีเพื่อนคนไหนในกลุ่มเล่นบ้าง
   - **เปลี่ยนอีโมจิ `☀️` / `🌙` หน้า Category อัตโนมัติ:** หน้าชื่อหมวดหมู่สถิติจะเป็น `☀️` ตอนกลางวัน และเปลี่ยนเป็น `🌙` ตอนกลางคืน พร้อมอัปเดตข้อความเดิมในห้อง `#📊・สถิติชาวแก๊ง` ทุกๆ 30 นาที
   - **`/stats` และ `/game_rank`:** เรียกดูสถิติรายบุคคลหรือเช็คอันดับแยกตามเกมได้ตลอดเวลา
5. **🤖 เพื่อน AI ประจำกลุ่ม ขับเคลื่อนด้วย Gemini (`cogs/gemini_friend.py`)**
   - แท็กชื่อบอท `@Bot` ในแชทเพื่อคุยโต้ตอบแบบกวนๆ เหมือนเพื่อนในกลุ่ม
   - `/roast` สั่งให้ AI แซวหรือเผาเพื่อนแบบฮาๆ
   - `/tldr` ให้ AI สรุปแชทย้อนหลังสูงสุด 150 ข้อความว่าเพื่อนเพิ่งเถียงเรื่องอะไรกัน
6. **🔊 ลูกเล่นห้องพูดคุย & Soundboard (`cogs/voice_magic.py`)**
   - **Join-to-Create:** กดเข้าห้อง `➕ สร้างห้องคุย` บอทจะสร้างห้องแยกให้ทันที เปลี่ยนชื่อห้องกวนๆ ได้ด้วย `/vc_rename` พอคุยเสร็จออกหมด ห้องจะลบตัวเองทิ้งอัตโนมัติ
   - **สั่งเล่นเสียงทันที (`/play_sound`, `/soundboard`, `/stop_sound`):** กดเล่นเสียงเอฟเฟกต์ในโฟลเดอร์ `sounds/` ตอนไหนก็ได้โดยไม่ต้องตั้งเป็นเสียงเปิดตัว! มีทั้งระบบ Autocomplete เลือกชื่อไฟล์ และแผงปุ่มกด `/soundboard` ไว้กดรัวๆ ในห้องแชท
   - **เสียงเปิดตัว (`/set_entrance_sound`, `/entrance_volume`, `/remove_entrance_sound`):** ตั้งเสียงประจำตัวเวลาเข้าห้องคุย พร้อมปรับลดความดังหรือปิดเสียงได้ตามต้องการ
7. **⏰ แจ้งเตือนความจำ (`cogs/events_reminders.py`)**
   - `/remind` ตั้งเวลาเตือนความจำในแชท

## 🚀 วิธีติดตั้งและรันบอท (จับมือทำทีละขั้น)

### ขั้นตอนที่ 1: สร้างบอทในเว็บ Discord Developer (ใช้เวลา 2 นาที)
1. ไปที่เว็บ [Discord Developer Portal](https://discord.com/developers/applications) แล้วกดปุ่ม **New Application** ตั้งชื่อบอทประจำกลุ่มได้เลย
2. ไปที่เมนู **Bot** ทางซ้ายมือ:
   - กดปุ่ม **Reset Token** แล้วก๊อปปี้ **Token** เก็บไว้
   - เลื่อนลงมาที่หัวข้อ **Privileged Gateway Intents** แล้ว **เปิดสวิตช์ทั้ง 3 อัน** (`Presence Intent`, `Server Members Intent`, `Message Content Intent`) จากนั้นกด **Save Changes**
3. ไปที่เมนู **OAuth2** ทางซ้ายมือ:
   - ในหัวข้อ **OAuth2 URL Generator** ให้ติ๊กช่อง `bot` และ `applications.commands`
   - เลื่อนลงมาที่ **Bot Permissions** ให้ติ๊กช่อง `Administrator` (เพื่อให้บอทสร้างห้อง ย้ายคน และเปลี่ยนชื่อแกล้งเพื่อนได้ครบ)
   - ก๊อปปี้ลิงก์ด้านล่างสุด (Generated URL) ไปวางในเบราว์เซอร์ เพื่อเชิญบอทเข้าเซิร์ฟเวอร์กลุ่มเพื่อนของคุณ!

### ขั้นตอนที่ 2: ตั้งค่าคีย์ในโปรเจกต์
1. คัดลอกไฟล์ `.env.example` ให้เป็นไฟล์ชื่อ `.env`:
   ```bash
   cp .env.example .env
   ```
2. เปิดไฟล์ `.env` แล้วนำ **Discord Token** และ **Gemini API Key** (ขอฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/app/apikey)) ไปใส่

### ขั้นตอนที่ 3: ติดตั้งไลบรารีและรันบอท
```bash
pip install -r requirements.txt
python bot.py
```

> **`/upgrade_server`**

บอทจะเนรมิตห้องและฟีเจอร์ทั้งหมดให้พร้อมเล่นกับเพื่อนทันทีครับ!
